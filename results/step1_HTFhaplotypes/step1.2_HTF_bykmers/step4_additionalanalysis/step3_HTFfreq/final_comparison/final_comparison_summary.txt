OVERVIEW
--------
This folder contains four key statistical comparison tables spanning
the upper, middle, and lower panels of Fig4C.

All tests compare O-antigen biosynthesis cluster (OBC) carriage between
Historical (pre-antibiotic era, n=38 total) and Modern (n=1312 OTU5)
P. viridiflava isolates, using different HTF haplotype groupings and
geographic stratification.

----------------------------------------------------------------
REPEATED DOWNSAMPLING — PURPOSE
----------------------------------------------------------------
Repeated random downsampling (used here): draw n=8 WITHOUT replacement
  from the Modern pool 1000 times and apply a two-sided exact binomial
  test (H0: OBC+ = 50%) within each drawn sample independently.
  Purpose: demonstrate that n=8 samples from the Modern pool cannot
  reliably distinguish their OBC composition from 50/50 — confirming
  that no cross-era comparison is warranted. This is NOT a test of
  Historical vs Modern difference.

----------------------------------------------------------------
BINOMIAL vs CHI-SQUARE for within-era comparisons
----------------------------------------------------------------
Binomial test (Tables 1 & 2): appropriate when outcome is BINARY.
  OBC+ vs OBC- is binary, so binomial is correct for testing whether
  one group is more common than the other within an era.
Chi-square goodness-of-fit (Table 1b): appropriate for comparing
  proportions across 3+ categories simultaneously (4 HTF groups).
  Using 4 separate binomial tests would inflate the Type I error rate
  (multiple testing); chi-square tests all 4 groups in one omnibus test.
