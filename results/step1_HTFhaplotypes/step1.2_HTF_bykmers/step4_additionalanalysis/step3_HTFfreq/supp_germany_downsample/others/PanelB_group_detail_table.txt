WHY DO THE ROUNDED PERCENTAGES NOT SUM TO EXACTLY 100%?
================================================================

Each group percentage displayed in the figure strip is independently
rounded to the nearest whole number (round(n_runs / 1000 * 100)).
This is a well-known rounding artefact:
  - The EXACT proportions always sum to 1.000 (100%) by definition,
    because every run lands in exactly one group.
  - However, rounding each proportion independently to integers can
    cause the displayed sum to be 99% or 101% rather than 100%.
    For example: 22.4% + 38.6% + 25.5% + 9.8% + 1.7% = 98.0/100
    but round() gives 22 + 39 + 26 + 10 + 2 = 99.
  - This is NOT an error in the data or sampling — it is solely a
    display/rounding artefact. The exact_pct column above always
    sums to 100.00%.

  Solution if exact 100% sum is required: use the largest-remainder
  (Hamilton) rounding method instead of independent rounding.
